ℹ️ How It Works

The Polyglot Cipher uses a 4-layer encryption algorithm that works across multiple languages and scripts. Unlike simple substitution ciphers, this cipher transforms characters across script boundaries — English text may become Tamil, Hindi, or Kannada characters and vice versa.

🔐 Cipher Layers

  • Layer 1 — Global Substitution: A key-derived permutation shuffles the entire character pool across all scripts
  • Layer 2 — Positional Shift: Each character position gets a unique shift value, making identical characters encode differently
  • Layer 3 — Secondary Substitution: A second independent permutation adds another layer of scrambling
  • Layer 4 — Feedback Cipher: Each character's encoding depends on the previously encoded character, creating cascading unpredictability

🌐 Supported Languages

  • English, French, German, Spanish (Latin script + extensions)
  • Hindi (Devanagari), Tamil, Kannada, Telugu, Malayalam
  • Bengali, Gujarati, Gurmukhi, Oriya
  • Diacritical letters: ā, ū, ṇ, ñ, ü, ö, etc.

🔒 Security Notes

  • Same key required: Use the exact same key to decode
  • Cross-script output: Input in one script may produce output in another — this is by design
  • Special characters preserved: Spaces, numbers, and punctuation pass through unchanged
  • Position-dependent: The same letter at different positions produces different cipher characters
