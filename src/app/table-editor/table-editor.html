About Table Editor

📝 Edit

  • Click any cell to start editing
  • Tab to move to the next cell
  • Enter to move down
  • Ctrl+Z / Ctrl+Shift+Z to undo/redo
  • Paste tab-separated data directly into cells

🔄 Transform

  • Transpose swaps rows and columns
  • Change text case: UPPER, lower, Capitalize
  • Remove duplicate rows or blank rows/columns

📤 Export

  • Convert to 10 formats: Markdown, HTML, CSV, JSON, XML, YAML, TOML, Jira, LaTeX, ASCII
  • Copy output to clipboard or download as a file
  • Import from Markdown tables or pasted data
